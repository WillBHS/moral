# 도덕 AI 도우미 — 배포 가이드

## 구조
```
/index.html        학생·교사가 보는 화면 전체
/prompts.json       AI에게 보내는 지침(문구) — 이 파일만 고쳐도 챗봇 말투/규칙이 바뀝니다
/api/create-room.js 교사가 API 키를 등록하면 방 코드를 발급하는 서버 함수
/api/chat.js         방 코드로 교사의 키를 찾아 Gemini를 대신 호출하는 서버 함수
```

학생 브라우저는 절대 실제 API 키를 보지 않습니다. 방 코드만 오갈 뿐, 진짜 키는 서버(정확히는 Upstash Redis 저장소)에만 있습니다.

## 처음 배포하는 방법 (한 번만 하면 됩니다)

### 1. GitHub에 코드 올리기
1. [github.com](https://github.com)에서 새 저장소(Repository)를 만듭니다 (Private으로 해도 됩니다).
2. 이 폴더 안의 파일들(`index.html`, `prompts.json`, `api/` 폴더)을 그대로 업로드합니다.

### 2. Vercel 계정 만들고 연결하기
1. [vercel.com](https://vercel.com)에서 GitHub 계정으로 가입합니다.
2. "Add New... → Project"에서 방금 만든 저장소를 선택하고 **Deploy**를 누릅니다.
3. 별다른 설정 없이 그대로 배포하면 됩니다(정적 파일 + `/api` 폴더를 Vercel이 자동으로 인식합니다).

### 3. 저장소(Upstash Redis) 연결하기 — 방 코드를 저장할 공간
1. 방금 만든 Vercel 프로젝트 화면에서 **Storage** 탭 → **Marketplace Database Providers** → **Upstash**를 선택합니다.
2. Redis 데이터베이스를 무료 플랜으로 생성하고, 지금 만든 프로젝트에 연결(Connect)합니다.
3. 연결하면 `KV_REST_API_URL`, `KV_REST_API_TOKEN`이라는 두 환경변수가 프로젝트에 **자동으로 추가**됩니다 — 따로 값을 입력하실 필요는 없습니다.
4. 환경변수가 추가된 뒤에는 **Deployments** 탭에서 최신 배포를 한 번 "Redeploy" 해주세요(환경변수는 재배포해야 적용됩니다).

### 4. 완료
이제 Vercel이 알려주는 주소(예: `https://당신의프로젝트.vercel.app`)가 실제 서비스 주소입니다. 이 링크를 선생님들께 공유하시면 됩니다.

## 이후 사용 흐름

1. **선생님**: 위 주소로 접속 → Gemini API 키 입력 → "방 만들기" → 방 코드·공유 링크·QR 코드가 뜸 → "확인, 테스트해볼게요"를 눌러 직접 사용해봄.
2. **학생**: 선생님이 공유한 링크(또는 QR)로 접속 → 키 입력 없이 바로 챗봇 사용.
3. 방은 **48시간** 동안 유효합니다. 그 이후엔 선생님이 다시 방을 만들어야 합니다(같은 키를 다시 입력하면 새 방이 만들어집니다).

## Gemini API 키는 어디서 받나요?

[Google AI Studio](https://aistudio.google.com/apikey)에서 구글 계정으로 로그인하면 무료로 즉시 발급받을 수 있습니다.

## 앞으로 수정할 때

- **문구·지침만 바꾸고 싶다면**: `prompts.json`만 고쳐서 GitHub에 올리면 끝입니다.
- **화면·로직을 바꾸고 싶다면**: `index.html` 또는 `/api` 안의 파일을 고쳐서 올립니다.
- GitHub에 올리기만 하면 Vercel이 1분 안에 자동으로 재배포합니다. 이미 발급된 학생 방 코드는 재배포해도 사라지지 않습니다(저장소와 코드는 분리되어 있습니다).

## ⚠️ 무료 API 키의 하루 사용량 한도 (중요)

2026년 9월 기준, Google AI Studio 무료 키의 하루 요청 한도는 모델마다 다릅니다.

| 모델 | 무료 티어 하루 한도 |
|---|---|
| Gemini 3.5/3.6/3.7/3.8 Flash (일반) | 약 20회 |
| Gemini 3.5/3.1 Flash-Lite | 약 500회 |

학생 한 명이 활동1~3을 끝까지 진행하는 데만 AI 호출이 10회 이상 필요합니다. **반 전체(20명 이상)가 하루 동안 함께 쓰기엔 무료 티어가 넉넉하지 않습니다.** 이 프로젝트는 한도가 더 넉넉한 Flash-Lite 계열을 우선 사용하도록 만들어져 있지만, 그래도 여러 반이 매일 쓰시려면:

- Google AI Studio에서 API 키에 **결제(Billing)를 연결**해 두시는 걸 권장합니다. Flash-Lite는 유료 전환해도 요청당 비용이 매우 저렴합니다(수업 규모에서는 하루 몇백 원 수준일 가능성이 높습니다 — 정확한 금액은 Google AI Studio 요금 페이지에서 확인해 주세요).
- 결제를 연결하면 하루 한도가 크게 늘어나서, 무료 티어의 제약이 사실상 사라집니다.

한도를 다 쓰면 화면에 "지금 이 키로 쓸 수 있는 AI 사용량을 다 썼어요"라는 안내가 뜹니다 — 오류가 아니라 정상적인 한도 초과 안내입니다.

## 보안 관련 참고사항

- API 키는 서버에만 저장되고 학생 화면에는 노출되지 않습니다.
- 다만 방 코드 자체를 아는 사람은 만료 전까지 그 교사의 키로 AI를 호출할 수 있으니, 공유 링크는 정말 필요한 사람에게만 전달해 주세요.
- Google AI Studio에서 API 키별로 **사용량 한도(청구 한도)**를 걸어두시면, 혹시 모를 오남용의 피해를 줄일 수 있습니다.
